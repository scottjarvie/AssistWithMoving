## Why this exists

Soft launch requires an owner to understand accounts, access, AI usage, storage,
errors, and support needs without casually browsing a household's private move
contents.

## Current truth

`/admin` is protected and signed-out requests redirect to Clerk. Source renders
account/usage/audit/support metrics, safe identifier search, feature flags,
storage and AI cost signals, and role checks; its own promise is visibility
“without private inventory browsing.” No admin account or provider data was
used, so live authorization, totals, query cost, redaction, feature-flag safety,
and support workflow are unproven.

**Priority:** Later unless admin proof unlocks a core private-workspace release.
**Change class:** verification gap with possible admin, query-efficiency, and
privacy fixes.

## Next safe action

Using a marked admin fixture and non-sensitive records, verify denial for
ordinary users, metric accuracy, search/redaction, cost-signal usefulness,
feature-flag auditability, and an end-to-end support lookup that does not expose
private inventory.

## Constraints

- Do not grant or persist admin access merely for this audit.
- Do not inspect production household content or change live feature flags.
- Admin totals must remain bounded and cost-aware at portfolio scale.
- Any auth/query/UI fix uses normal PR, CI, preview, and deployment.

## Completion evidence

- Signed-out and non-admin fixtures are denied; a marked admin sees only the
  intended safe aggregates and identifier-level support detail.
- Totals reconcile to fixture data, expensive reads are bounded/indexed, and
  storage/AI/access signals have documented units and refresh behavior.
- Search, errors, feature flags, and audit history redact private contents and
  log privileged actions.
- Full CI, query-cost evidence, preview/live proof, and independent audit pass.

## Unknown or access limitation

Admin identity, production metrics, feature-flag behavior, and provider usage
were deliberately not accessed. Source presence is proven; live readiness is
unknown.
