## Why this exists

Bring-your-own AI is central to Moving's identity. Setup instructions and tool
claims must be both easy for a person to follow and proven against the hosted
surface before the product treats them as Current.

## Current truth

`/ai`, `/ai/start`, `/mcp/guide`, `/llms.txt`, the REST guide, and two MCP code
surfaces exist. The local stdio discovery proof passed 20 checks and advertised
87 tools with a dummy key. The live unauthenticated OAuth discovery proof passed
10 checks, including the challenge, protected-resource metadata, dynamic client
registration endpoint, PKCE S256, and required scopes. However, `/ai.txt`
returns HTTP 404, and this audit did not register a client, sign in, exchange a
token, call a hosted tool, or verify data isolation. Discovery is not an
authenticated end-to-end proof.

**Priority:** Now. **Change class:** verification gap with likely product and
documentation changes.

## Next safe action

On a normal branch and preview, add the canonical `/ai.txt` plain-text surface,
reconcile claims across `/ai`, `/ai/start`, `/mcp/guide`, `/llms.txt`, and the
API guide, then run one marked-test-account OAuth connection and bounded
read-only tool scenario in a supported client. Make any unproven client-specific
claim conditional or Coming soon.

## Constraints

- Use only a marked non-production test account and non-sensitive fixture move.
- Do not broaden OAuth scopes, provider access, secrets, or production data.
- Stop for MFA, sign-in identity ambiguity, or a new durable-access grant.
- Treat route/code/docs changes as software; they never use the state lane.

## Completion evidence

- `/ai.txt` returns HTTP 200 plain text and contains the current product promise,
  setup route, MCP endpoint, auth method, and honest capability boundaries.
- A supported hosted client completes discovery, authorization, token exchange,
  `tools/list`, one bounded read-only call, disconnect/revocation, and an
  isolation check using marked test data; screenshots/logs redact credentials.
- `/ai`, `/ai/start`, `/mcp/guide`, `/llms.txt`, and the API guide agree on the
  endpoint and Current versus Coming soon claims.
- Full CI, normal preview build, and post-deploy public route checks pass.

## Unknown or access limitation

No authenticated client or test-account access was used in this audit. Hosted
tool execution, client compatibility, revocation UX, and cross-user isolation
therefore remain unproven rather than failed.
