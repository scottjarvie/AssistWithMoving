## Why this exists

Moving's Queue is useful only when a person's chosen AI can discover and finish
bounded work without gaining broad write access or inventing objectives.

## Current truth

Protected-branch source now exposes canonical list/get/claim/release/Needs You/complete/
failure commands through the OAuth Convex gateway and the API-key REST/stdio MCP
surface. Independent `queue/read` and `queue/write` scopes, live move access,
owner/delegation checks, expected versions, idempotency, claim leases, activity,
and audit attribution are enforced. The OAuth Queue implementations are
internal function references callable through the identity-injecting gateway,
so the new tools do not add a public Convex function that accepts a spoofable
caller subject. Idempotency replay lookup now happens only after current
owner/delegation authorization. Agent tools cannot create directives or
inherit inventory, plan, export, member, purchase, publishing, identity, or
outside-world authority. Focused capability and service tests pass locally.

**Priority:** Now. **Change class:** agent/API software and verification.

## Next safe action

Run both agent surfaces against a marked synthetic move after protected deploy:
read -> claim -> request input -> human response -> reclaim -> durable result -> human
inspection. Verify missing scope, wrong move, wrong owner, revoked/disabled key,
stale version, duplicate request, and expired lease failures.

## Constraints

- The OAuth gateway derives identity from its verified caller subject; the
  API-key path derives the human owner and move restriction from the key.
- All agent-facing Convex failures must remain readable `ConvexError`s.
- Queue access never substitutes for the separate permission of the domain write.
- Do not add an agent tool that invents new Queue objectives.

## Completion evidence

- OAuth and API-key/stdio catalogs agree on the seven canonical Queue tools.
- Cross-user, cross-move, missing-scope, revoked-key, and delegation tests pass.
- Every command records the person, acting AI/key, state transition, message,
  version, and idempotent result without duplicate activity.
- CI, exact preview/production deployment, marked-account browser/MCP proof, and
  independent audit are linked.

## Unknown or access limitation

No OAuth token, API key, marked account, or production data was used in this
task. Provider-backed end-to-end proof remains unavailable until normal release.
