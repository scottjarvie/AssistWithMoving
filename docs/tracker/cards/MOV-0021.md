## Why this exists

A moving workspace must stay understandable on phone, tablet, desktop, and
wide screens when data is empty, loading, dense, offline, unauthorized, or
failed—not only on its public landing pages.

## Current truth

The broad audit program is superseded as a standalone backlog item. Later
protected Queue and first-run work exercised phone/desktop rendering, empty and
populated Queue states, signed-in app shells, keyboard/accessibility checks, and
real production paths with marked removable fixtures. Those receipts are useful
but do not prove every authenticated route or state. Future UI Work Orders must
carry proportional responsive and system-state proof for the routes they change
instead of reopening a ceremonial whole-product matrix.

## Next safe action

Create a focused Card only when a current first-use or changed-route scenario
reproduces a concrete overflow, focus, loading, empty, denied, or error defect.

## Constraints

- Do not claim all pages are accessible from a source scan or one viewport.
- Preserve dense planning utility while preventing clipped or unreachable work.
- Include fixed bottom navigation, modals/sheets, virtualized tables, uploads,
  long labels, and software keyboard effects.
- Resulting UI/test changes use normal safeguards.

## Completion evidence

- A durable matrix covers Moves, selected move, Queue, Items, Movable Units,
  Capture/Photos, Spaces/Plan, Load/Move Day, Packets, Settings, `/me`, and Admin
  where authorized across essential states and viewports.
- No critical overflow, obscured action, focus trap/loss, unlabeled essential
  control, keyboard dead end, or inaccessible error/empty state remains.
- Screenshots, semantic snapshots, interaction traces, issue reproduction, full
  CI, and independent review are linked.
- Unavailable feature-flag/provider states remain labeled unknown, not passed.
- [x] The tracker no longer carries an unbounded all-routes audit as active
  product work; responsive proof remains a requirement inside bounded Work
  Orders such as `MOV-WO-009`.

## Unknown or access limitation

Admin, every packet state, every dense table, and offline behavior remain
unproved globally. Closing this audit program does not relabel those paths.
