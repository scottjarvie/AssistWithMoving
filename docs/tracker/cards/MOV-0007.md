## Why this exists

A new person should be able to start a private move, understand what matters
now, leave one Queue handoff, and return to the same durable context without
learning the product's advanced inventory, packet, or integration model first.

## Current truth

The retained empty account now proves ordinary sign-in, the branded empty
workspace, Queue, and AI Connections. A later removable production fixture
proved creation of a private move, one Queue handoff, an MCP-saved source-backed
result, return through Queue and Move overview, and permanent cleanup. That is
strong workflow evidence and must not be rerun as backlog theatre. What remains
unproved is the simplest product-native journey for a person who is not starting
with MCP: create the move, add only the minimum useful context, understand its
private boundary, use Queue, leave, and return without advanced setup.

## Next safe action

Using the retained non-privileged identity and removable fixture data, walk the
normal UI from empty workspace to one small private move, its route/room or
belongings context, one Queue handoff, return visit, and cleanup. Fix only
friction that blocks that first useful loop; defer packets, admin, stats,
provider workflows, and broad audits.

## Constraints

- Do not use Scott's production data or another person's account.
- Do not create provider settings, billing, domain, auth-policy, or durable
  access changes without explicit authority.
- Separate verified product defects from harness slowness and unavailable proof.
- Any resulting software fix uses a branch, PR, full CI, and normal deployment.

## Completion evidence

- A recorded first-time scenario proves sign-in, empty state, one small private
  move, minimal context, Queue handoff, reload/return, and exact cleanup on phone
  and desktop without requiring advanced setup.
- The UI plainly says who can see the new move and exposes no other account's
  data; no broad sharing or export matrix is required for this tranche.
- Focused regression tests and the normal full CI result are linked; old local
  timeout triage is not revived when current protected suites are green.
- An independent reviewer audits the evidence separately from execution.

## Unknown or access limitation

Advanced uploads, export/share matrices, admin, offline recovery, and every move
type remain outside this first-use outcome.
