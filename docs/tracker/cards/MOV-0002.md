## Why this exists

An AI or owner must be able to pull this repository and continue ordinary work
without reconnecting a separate planning service. Mandatory Linear language
would undermine the repo-owned tracker and create a needless external gate.

## Current truth

README described Linear as issue tracking, and several historical audit handoff
documents instructed workers to move Linear issues before implementation. The
portfolio owner has explicitly removed that requirement. Historical MOVE ids
remain useful evidence but are not authority or a prerequisite.

## Next safe action

Merge the revised instructions with the tracker installation, then record the
merge evidence and close this Card through the state-only proof commit.

## Constraints

- Do not reconnect, query, or depend on Linear.
- Preserve historical ids and completed audit facts where they help provenance.
- Cards / Work Orders / Guide own current scope, approval, and handoff truth.
- GitHub PRs and checks remain implementation and integration evidence.

## Completion evidence

- Repository and AI instructions link this tracker and state Linear is optional
  historical context only.
- Applicable handoff documents no longer require Linear actions.
- A cold-start reader can identify current work from this repository alone.
