## Why this exists

The first page should explain the durable move-planning product a household is
joining, not only list inventory features. Human guidance must lead to readable
pages rather than protocol endpoints.

## Current truth

The live home page is responsive and distinctive, but its primary promise is
“The manifest for everything that moves.” It does not state the Project
Philosophy's durable move-plan identity or the Core house sentence, and it links
to a separate FAQ rather than showing essential FAQ truth on the home page.
The live FAQ's “MCP” link targets `/mcp`, whose correct protocol behavior is
HTTP 405 on a browser GET; the readable guide is `/mcp/guide`. The current
public footer has no verified family-project row or shared Support Desk link.

**Priority:** Now. **Change class:** product change.

## Next safe action

Use a normal product PR to align the home promise with the canonical Moving
identity, surface a small current/coming-soon FAQ on the home page, and route
human navigation to readable guidance. Preserve the MovingManifest name and
the product's inventory, packing, evidence, load-planning, and document focus.

## Constraints

- Do not turn Moving into a generic Assist template or rename the shipped app.
- Do not present unverified capabilities, Support, or family destinations as
  active. Concrete unfinished destinations must be visibly Coming soon or
  omitted.
- Keep `/mcp` as the protocol endpoint; fix human links, not protocol behavior.
- Application and UI changes require normal PR, CI, preview, and deployment.

## Completion evidence

- At 360, 768, and 1366 CSS pixels, the home page has no horizontal overflow
  and states the durable move-plan identity, house sentence, and truthful FAQ.
- Every visible public CTA and navigation link is crawled and returns the
  intended readable page, redirect, or explicitly labeled Coming soon state;
  no human-facing link opens `/mcp` as a document.
- Copy review maps each present-tense claim to repository and live evidence.
- Full CI and a normal preview/production build pass for the software change.

## Unknown or access limitation

The shared family-row destinations and portfolio Support Desk URL were not
available as verified current inputs in this audit. They must not be invented.
