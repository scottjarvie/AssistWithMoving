## Why this exists

A person's chosen AI should be able to do useful move work without losing the
result in chat, dumping the database, or silently gaining Queue authority.

## Current truth

The eight-tool Moving-native stateless OAuth foundation is released in
production through PR `#180` at merge `0a5e0eb`. It derives identity and move
access server-side, verifies an issuer-signed audience-bound access token, uses
bounded reads and replay-safe writes, preserves source-check truth, saves
complete multi-record results, and shows those results in the move workspace.
The older OAuth catalog remains at `/mcp/connect`; API-key HTTP/stdio surfaces
remain separate. Exact-head and post-merge CI, the full 1,040-test suite,
Convex/Vercel production deployment, public discovery, signed-out privacy, and
an official SDK anonymous-client challenge all pass.

**Priority:** Now. **Change class:** agent/API software, schema, UI, public docs,
and release truth.

## Next safe action

Use a sanctioned disposable identity and cleanup path if named-client OAuth
consent/refresh/disconnect and real private-media rendering become a priority.
Do not infer those paths from the completed anonymous and isolated proof.

## Constraints

- Preserve Moving's own move, location, inventory, evidence, planning result,
  source-check, and Queue vocabulary.
- Derive person and workspace identity from the verified server token; never
  accept an arbitrary user or household selector.
- Keep reads bounded and writes idempotent, optimistic, attributable, and
  visible in the normal web product.
- Do not expose canonical OAuth Queue transitions until a distinct chosen-AI
  grant is proven.
- Do not use real production data, secrets, billing, DNS, or provider-policy
  changes for proof.

## Completion evidence

- `/mcp` advertises exactly the eight documented workflow tools through modern
  and stateless legacy protocol requests.
- Anonymous, wrong-audience, expired-token, cross-move, replay, conflict, and
  correction behavior is covered by isolated tests.
- A complete synthetic move result saves rooms, inventory, planning records,
  and source provenance once and is readable through search and the web UI.
- Full local gates, protected CI, exact deployment, public discovery, and
  signed-out privacy pass at merge `0a5e0eb`, Actions run `31652048912`, and
  Production deployment `dpl_AxReSqDrxvy6vMoL13Q5PYumxmPz`.
- Public `/mcp` returns the RFC 9728 challenge, protected-resource metadata
  names the exact resource and Clerk authorization server, compatibility and
  API-key doors retain their separate refusals, `/mcp/guide` and `/ai.txt`
  return 200, and signed-out `/app/moves` redirects to sign-in.

## Unknown or access limitation

A real named client OAuth consent/refresh/disconnect lifecycle and private image
render require a sanctioned disposable account path. They must not be inferred
from local JWT or public anonymous proof.
